# Applied Deep Learning

Coursework notebooks covering neural networks, model comparison, regularization, and transfer learning.

## Notebooks

All seven notebooks from the AAI640 workspace are kept in [`notebooks/`](notebooks/):

- `AAI640_neural_network_assignment.ipynb` — California Housing regression with neural networks.
- `Michael AAI640 neural network.ipynb` — another California Housing neural-network notebook.
- `AAI640_assignment_2_revised.ipynb` — revised Fashion-MNIST initialization and regularization experiments.
- `Michael assignment 2.ipynb` — another Fashion-MNIST assignment notebook.
- `hyperparameter_ass3.ipynb` — CIFAR-10 hyperparameter tuning.
- `Michael_Kelly_transfer_learning.ipynb` — CIFAR-10 CNN transfer learning.
- `In-class Assignment.ipynb` — text representation and topic modeling. This is included because this repository consolidates the seven supplied course notebooks; its subject is NLP.

The two California Housing notebooks and two Fashion-MNIST notebooks are preserved separately because they are distinct files/versions.

## Running the notebooks

Each notebook lists or imports the packages it uses. Open a notebook in Jupyter and run its cells in order. Some notebooks download public datasets or pretrained weights when first run. Training time and package requirements vary by notebook.

These are coursework notebooks, not a single installable Python package. Review the notebook and its outputs before relying on its results.
